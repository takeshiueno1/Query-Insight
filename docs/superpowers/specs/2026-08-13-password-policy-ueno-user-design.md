# パスワードポリシー変更・確認ユーザー追加 設計

## 目的

ログイン画面で短い確認用パスワードが拒否される問題を解消し、利用者が指定したローカル確認用アカウントで動作確認できるようにする。

## 対象範囲

- パスワードの入力条件を8〜128文字へ変更する。
- 使用可能文字を半角英字と半角数字に限定する。
- 英字と数字をそれぞれ1文字以上必須とする。
- ログイン画面、認証API、初期管理者設定の入力条件を統一する。
- `local` プロファイル専用の一般ユーザー `ueno` を追加する。
- `ueno` のパスワードは `5050Rock`、データ範囲は `SELF` とする。
- README、要件、ユースケース、非機能要件、トレーサビリティ、デプロイ手順の関連記述を同期する。

## 対象外

- パスワード変更・再設定APIの新規実装。
- 既存アカウントのパスワード強制変更。
- 本番環境への確認用アカウント作成。
- JWT、Refresh Token、レート制限、Argon2id設定の変更。

## 実装方針

パスワード条件はフロントエンドとバックエンドの両方で検証する。フロントエンドは送信前に日本語エラーを表示し、バックエンドは直接APIを呼ばれても同じ条件を満たさない入力を400で拒否する。認証失敗時の401応答は従来どおり、ログインIDの存在有無を区別しない。

ローカル確認用ユーザーは既存のリアリティデータ初期化処理へ追加する。ユーザー名、パスワード、権限はローカル環境だけに限定し、平文パスワードをDBやログへ保存しない。DBには既存と同じArgon2idハッシュだけを保存する。

## 検証

- 8文字の半角英数字混在パスワードを受理する。
- 7文字以下を拒否する。
- 記号、空白、全角文字を含むパスワードを拒否する。
- 英字のみ、数字のみを拒否する。
- `ueno / 5050Rock` でログインでき、`GENERAL / SELF` が返る。
- 既存認証テスト、フロントエンドテスト、Lint、ビルドを通す。
- 起動中のローカル環境を更新し、ブラウザからログインできることを確認する。
