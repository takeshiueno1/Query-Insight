# プロダクト概要

## 解決する課題

- 社員のスキル、資格、経歴、評価が分散し、最新状態と根拠を追跡しにくい。
- 人材検索、育成計画、評価面談の準備に手作業が多い。
- 本人・上長・管理者の操作範囲と変更履歴を一貫して管理できない。

## 対象ユーザーと提供価値

| 利用者 | 提供価値 |
| --- | --- |
| 社員 | 自身の経験・能力を一か所で更新し、評価状況と成長課題を把握できる |
| 上長 | 直属部下の承認済みタレント情報を根拠として、6軸をS/A/B/C/D/Fで評価できる |
| 人事・管理者 | 人材情報を横断検索し、評価制度・組織・権限・監査を統制できる |

## 対象範囲

- 共通ナビゲーション、ログイン、セッション更新、パスワード関連
- ダッシュボード、社員検索、社員詳細・登録・編集
- スキル、資格、職務経歴、案件経歴
- 承認済みタレント情報から自動算出する自己ステータス、上長評価、評価履歴
- 評価期、評価項目、グレード境界、組織、アカウント、マスタ管理
- 通知、承認、監査ログ
- 将来のAI分析に備えた無効化可能な境界API

## 初期成果物の範囲

現在のMVPは、認証、ダッシュボード、社員検索・登録・詳細、タレント申請・直属上長承認、自己ステータス、上長評価・最終承認・本人公開、通知、監査、ローカル分析をDBまで接続している。評価期間・評価基準、組織・所属、アカウント・権限、マスタ管理、パスワード変更・再設定、評価履歴比較はDB基盤または画面骨格までで、後続実装が必要である。受領資料にあった本人の自己評価入力は廃止済みで、現行の一般利用者導線には表示しない。

## 対象外・保留

- 本番デプロイ、クラウドリソース作成、SSO・メール連携
- AIベンダーへの実データ送信
- 人事基幹システムとの同期
- 管理画面からの自己ステータス配点・ランク境界変更

## 成功指標

資料には測定可能な目標値が確定していない。正式リリース前に、月間利用率、プロフィール更新率、評価期限内完了率、人材検索時間、問い合わせ件数を基準値と目標値付きで決定する。
